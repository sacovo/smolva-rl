SmolVLA RL Training

Reinforcement Learning for robotic rovers using Vision-Language-Action models.

What & Why

  • Integrates SmolVLA with Reinforcement Learning (RECAP).
  • Enables high-resolution vision-language models for robot control.
  • Addresses data efficiency and generalizability in robotics.
  • Co-trains VLM backbones on large-scale robotics datasets.

How

  • Uses FAST tokenizer for efficient large-scale data processing.
  • Implements distributional RL (C51) for the VLM critic.
  • Leverages PyTorch Accelerate for distributed multi-GPU training.
  • Utilizes SmolVLM2-500M as the core pre-trained backbone.
